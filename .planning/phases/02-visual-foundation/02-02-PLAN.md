  <action>
    Implement `SlideScale.client.ts`:
    - Listen for `window` resize events.
    - Calculate scale: `Math.min(innerWidth / canvasWidth, innerHeight / canvasHeight)`.
    - Apply `transform: scale(s)` to `.slide-content`.
    - Calculate offsets to center the container: `left = (innerWidth - canvasWidth * s) / 2`, `top = (innerHeight - canvasHeight * s) / 2`.
    - Apply offsets to `.slide-container` via `translate` or `margin`.
    - Wrap the slide content in `SlideView.astro` with `SlideContainer` and initialize the scaler.
