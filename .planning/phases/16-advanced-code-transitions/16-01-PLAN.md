    - Should output a `<div class="shiki-magic-move-container" data-tokens="..." data-options="..."></div>` element.

    3. Implement the transformation logic:
       - Use a regex or state machine to find ````md magic-move` ... ```` blocks.
       - Extract steps (each step is a standard code fence).
       - Tokenize using the existing Shiki setup if possible, or a new highlighter if needed.
       - Use `toKeyedTokens` from `shiki-magic-move/core`.
