  <action>
    Create the client-side logic for Shiki Magic Move:
    1. Import `MagicMoveRenderer` from `shiki-magic-move/core`.
    2. Import `LZString` from `lz-string`.
    3. Import `$clicks` from `@slidastro/client`.
    4. Implement `initMagicMove()`:
       - Find all `.shiki-magic-move-container` elements.
       - For each element:
         - Decompress `data-tokens` using `LZString.decompressFromBase64`.
         - Parse `data-options` (JSON).
         - Initialize `new MagicMoveRenderer(el)`.
         - Get `clickStart` from `data-click-start`.
         - Create an `update(clickCount)` function:
           - Calculate `stepIndex = Math.max(0, clickCount - clickStart)`.
           - Cap `stepIndex` at `tokens.length - 1`.
           - If it's a new step, call `renderer.render({ tokens: tokens[stepIndex], ...options })`.
         - Initial update with current `$clicks.get()`.
         - Listen to `$clicks` and call `update`.
  </action>
