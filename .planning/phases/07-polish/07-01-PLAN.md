# Plan 07-01: Unified Click Engine & step-click Support

This plan refines the click interaction system to use `step-click` as the framework-neutral naming for animations, including support for attributes on any element and advanced click ranges.

## Goals
1. Support `step-click` and `<step-click>` for animations.
2. Support `step-click` as an attribute on any element.
3. Support click ranges (e.g., `step-click="1-3"`).
4. Implement a unified click engine that handles `step-click`.
5. Improve animation smoothness by using stable CSS classes.
6. Remove legacy `v-click` support.

## Proposed Changes

### 1. `packages/core/src/renderer.ts`
- Update `renderSlide` to:
  - Support `<step-click>` tags.
  - Support `step-click` attributes on any HTML-like tag in Markdown.
  - Use a regex-based pre-processor to find elements with `step-click` attributes and convert them to `data-step-click` attributes with appropriate indices.
  - Ensure all clickable elements have a common class, e.g., `slidastro-click`.
  - Maintain an auto-incrementing click index for elements without explicit indices.
  - Remove `v-click` regex replacement.

### 2. `packages/core/src/components/Navigation.client.ts`
- Update `applyClicks`:
  - Parse `data-step-click` values (could be a single number or a range like `"1-3"`).
  - Define visibility logic:
    - If value is `n`: visible if `currentClick >= n`.
    - If value is `start-end`: visible if `currentClick >= start && currentClick <= end`.
  - Update `totalClicks` calculation:
    - Scan all `data-step-click` elements.
    - Find the maximum index mentioned (either as a single value or as the `end` of a range).
- Ensure `applyClicks` uses `visibility: hidden` and `opacity` for smoother transitions.

### 3. CSS Updates
- Update `packages/core/src/templates/SlideView.astro`:
  - Rename `.slidev-vclick` to `.slidastro-click`.
  - Rename `.slidev-vclick-hidden` to `.slidastro-click-hidden`.
  - Use `visibility: hidden` instead of `pointer-events: none` in `.slidastro-click-hidden`.

## Verification Plan

### Automated Tests
- Create a new test in `packages/core/test/clicks.test.ts` to verify:
  - `step-click` tags are correctly transformed.
  - `step-click` attributes on `<p>`, `<span>`, etc., are correctly transformed.
  - Click indices are correctly auto-incremented.
  - Range parsing correctly identifies max clicks.

### Manual Verification
- Create a demo slide deck with:
  - `<step-click>Step 1</step-click>`
  - `<p step-click>Step 2</p>`
  - `<div step-click="1-3">Visible during 1, 2, 3</div>`
  - `<span step-click="4">Visible from 4</span>`
- Verify navigation between steps 0 to 5.
- Confirm smoothness of animations.
